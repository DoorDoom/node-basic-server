# Node basic server

The project for RS-School course nodejs-2026-q1.

---

## Tech Stack

- Node.js
- TypeScript
- Fastify
- Node test runner (`node:test`)
- ts-node

---

## Installation

```npm
npm install
```

---

## Environment

Expected PORT in ./environments/.env

```
PORT=3000
```

---

## Start project in modes

Develop:

```npm
npm run start:dev
```

Build:

```npm
npm run start:prod
```

Test:

```npm
npm run test
```

Multi processing server:

```npm
npm run start:multi
```
